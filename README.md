# Catllaràs · Guia de ruta (28–29/11/2026)

App web offline per al guia de la travessa amb bivac a la serra del Catllaràs: horaris, límits de decisió, plans B i C, mapa amb GPS, coordenades per al 112 i material.

**Instal·lar a l'iPhone:** obrir la web amb Safari amb cobertura → Compartir → «Afegir a la pantalla d'inici». Després funciona sense connexió.

**Android:** obrir amb Chrome → menú → «Instal·lar aplicació».

Fitxers: `index.html` (l'app sencera), `sw.js` (funcionament offline), `manifest.webmanifest` i icones.

Per actualitzar l'app, canvieu `CACHE` a `sw.js` (p. ex. `catllaras-v2`) perquè els mòbils descarreguin la versió nova.
